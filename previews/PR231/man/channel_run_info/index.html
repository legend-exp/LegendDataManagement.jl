Channel, Run and Partition Information

The run information lists the runs of a data production with their start keys and livetimes, the channel information gives the status and hardware properties of each channel in a run or period, and the partition information groups runs across periods per detector. All three are Tables of TypedTables.jl built from the metadata (see Metadata and Validity).

using TypedTables, PropertyFunctions, Unitful

Runs are selected by tuples of identifiers. (period, run) is a LegendDataManagement.RunSelLike, (period, category) a LegendDataManagement.PeriodSelLike and (period, run, category) a LegendDataManagement.RunCategorySelLike; the elements can be identifier objects such as DataPeriod(2), symbols such as :p02 or strings (see Identifiers and FileKeys).

Run Information

runinfo returns one row per run of data.dataset (all runs of the metadata for the default dataset, see LegendData). The columns are period, run, keys (a DataSet with the DAQ cycle keys of all categories of the run) and one column per data category found in the metadata.

rinfo = runinfo(l200, :p02)

((:period, :run, :keys, :ath, :anc, :acs, :tst, :ant, :aph, :anp, :phy, :cal, :pzc, :fft, :ssc), 8)

Rows are filtered with PropertyFunctions.filterby and @pf (see Property Functions and Expressions). This selects the calibration runs of a period that are analysis runs:

first(rinfo_cal).cal.startkey

Start Keys, Livetime and Analysis Runs

start_filekey gives the first file key of a run and category, or missing if the metadata has none. livetime gives the livetime in seconds as a Unitful quantity, NaN seconds if the metadata has none.

start_filekey(l200, (:p02, :r006, :cal))
FileKey("l200-p02-r006-cal-20220701T000000Z")
start_filekey(l200, mfk)
FileKey("l200-p02-r006-cal-20220701T000000Z")
livetime(l200, (:p02, :r006, :phy))
10000.0 s
ustrip(u"s", livetime(l200, (:p02, :r006, :cal)))
NaN

The exposure is calculated from the livetime (see Exposure and Livetime).

is_lrun tells whether a run exists in the metadata with a start key, and is_analysis_run whether it is an analysis run of its category. analysis_runs lists all analysis runs of a category. The analysis runs are those listed in the metadata datasets/runlists for data.dataset, with the run list valid for the default dataset.

is_lrun(l200, (:p02, :r006, :cal)), is_lrun(l200, (:p02, :r099, :cal))

Ignored DAQ Cycles

bad_filekeys returns the set of file keys that the metadata datasets/ignored_daq_cycles lists, e.g. cycles without usable data. load_key selects one of the lists of that file; the default :all merges them.

length(bad_filekeys(l200))
3
bad_filekeys(l200; load_key = :unprocessable) ⊆ bad_filekeys(l200)
true

Channel Information

channelinfo returns a table with one row per channel. The selection determines the time and category whose metadata is used. These forms are equivalent for the run of mfk:

chinfo = channelinfo(l200, mfk)
chinfo == channelinfo(l200, ValiditySelection(mfk)) == channelinfo(l200, (:p02, :r006, :cal)) == channelinfo(l200, :p02, :r006, :cal)
true

The selection can be

  • a FileKey or LegendDataManagement.ValiditySelection,
  • a run (period, run, category), or (period, run) for the category :cal,
  • a period with a category (period, category), or a period alone for the category :cal.

The selections can also be passed as separate arguments, like channelinfo(l200, :p02, :r006, :cal).

For a period, the information of all runs of the category is merged into one table. The status columns processable, usability, is_blinded, psd_usability and the PSD *_status columns take the best value over the runs; all other columns have to be identical in every run. Only analysis runs are used unless only_analysis_runs = false.

Columns

The table has the columns detector, channel, fcid, rawid, system, processable, usability, is_blinded, psd_usability, low_aoe_status, high_aoe_status, lq_status, ann_status, coax_rt_status, is_bb_like, partition, det_type, location, detstring, fiber and position. Keywords

  • system: Keep only the channels of one system, e.g. :geds, :spms or :puls. Default is :all.
  • only_processable: Keep only channels that are marked as processable. Default is false.
  • only_usability: Keep only channels with this usability, e.g. :on. Default is :all.
  • sort_by: Column to sort by, compared as strings; :string sorts by detector string and position. Default is :detector.
  • extended: Add hardware and production columns, see below. Default is false.
  • verbose: Warn if the FCCD of a detector is missing for extended = true. Default is true.
  • only_analysis_runs: Use only analysis runs for a period selection. Default is true.
  • explode_partitions: One row per detector and partition, see below. Default is false.
chinfo_geds = channelinfo(l200, :p02, :r006, :cal; system = :geds, only_processable = true)

Extended Information

With extended = true the table has the additional columns cc4, cc4ch, daqcrate, daqcard, hvcard, hvch, enrichment, mass, total_volume, active_volume and fccd. The enrichment, FCCD and active volume carry uncertainties (Measurements.Measurement), and all have units: mass in kg, enrichment in percent, fccd in mm and the volumes in cm$^3$. The active volume is the detector volume without the dead layer of thickness fccd; the total volume is the volume for fccd = 0. Values missing in the metadata are NaN, and a missing FCCD is set to zero with a warning if verbose.

chinfo_ext = channelinfo(l200, mfk; extended = true, verbose = false)
(chinfo_ext.detector, chinfo_ext.mass)
(DetectorId[DetectorId("B99000A"), DetectorId("PULS01"), DetectorId("V99000A")], Unitful.Quantity{Float64, 𝐌, Unitful.FreeUnits{(kg,), 𝐌, nothing}}[1.0 kg, NaN kg, 2.5 kg])

Partitions of Channels

The column partition holds the DataPartition of each detector that contains the run, missing for a detector in no partition. If the metadata has no groupings for the category (datasets/<category>_groupings), partition is missing for every detector. For a period selection the column holds the vector of the partitions that contain the period.

With explode_partitions = true the table has one row per detector and partition with a single DataPartition in partition; detectors in no partition are left out. This is the form for the processing of partitions that span several periods.

chinfo_parts = channelinfo(l200, :p02, :cal; system = :geds, explode_partitions = true)
(chinfo_parts.detector, chinfo_parts.partition)
(DetectorId[DetectorId("B99000A"), DetectorId("V99000A")], DataPartition[DataPartition(calpartition001a), DataPartition(calpartition001a)])
Note

The result of channelinfo is cached per LegendData object and selection. Changes of the metadata on disk are not visible to the same LegendData object.

Partition Information

A data partition groups runs of one category, possibly from several periods, for a joint analysis. The partitions are defined per detector in the metadata datasets/cal_groupings and datasets/phy_groupings, merged over the default entry that holds the partitions of all detectors. A DataPartition such as DataPartition(1) (calpartition001a) names a partition.

partitioninfo returns the partitions of a detector in these forms:

  • partitioninfo(data, det, category): A dictionary that maps each partition to a table with the columns period, run and a column named like the category with its run information (see above). Only analysis runs are included.
  • partitioninfo(data, det, partition): The table of one partition.
  • partitioninfo(data, det, category, period): The partitions that contain the period.
  • partitioninfo(data, det, category, period, run): The partitions that contain the run.
partitions = partitioninfo(l200, :V99000A, :cal)

A Symbol or String in place of the category in partitioninfo(data, det, name, category) is read as a partition or a period, and a ChannelId in place of the detector is converted with the channel information of the first calibration run. An ArgumentError is thrown if the metadata has no groupings for the category.

get_partition_combined_periods lists the periods that share a calibration partition with a period for the given detectors. cal_groupings_default and phy_groupings_default return the runs of the default groupings as a table with the columns period and run.
