# Reading data with `read_ldata`

The `read_ldata` function is provided by the `LegendHDF5IO` extension, which is
loaded when both `LegendDataManagement` and `LegendHDF5IO` are in use.

See the [`LegendHDF5IO` extension](@ref) for the existing examples of selecting
files and fields, filtering events, handling missing channels, and loading data
in parallel. For the initial dataset setup and discovery workflow, see
[Data access and discovery](@ref). Complete function signatures are listed in
the [API](@ref).
